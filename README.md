# 여순광 맛집 지도 🗺️

여수·순천·광양 맛집을 카카오맵 위에 보여주는 한 페이지짜리 웹사이트입니다.

## 기능
- 지역(여수/순천/광양)·종류 필터, 식당 이름·메뉴 검색
- 맛집 목록 (PC: 왼쪽 목록 / 모바일: 지도 아래 접었다 펴는 목록)
- 지역별 마커 색(여수 파랑·순천 초록·광양 주황), 가까운 마커는 숫자로 묶어 표시
- ⭐ 즐겨찾기: 식당마다 ☆ 저장 → "즐겨찾기" 버튼으로 모아 보기 (이 브라우저에만 저장)
- 🕒 영업 중: 영업시간을 입력한 식당은 "영업 중/영업 종료" 표시와 필터 제공
- 공유: 식당 링크(`?place=식당이름`)를 보내면 받은 사람 화면에서 그 식당이 바로 열림
- 📍 내 주변: 현재 위치 기준 가까운 순 정렬 (https 주소에서만 동작)
- 카카오맵 길찾기·상세보기·전화 바로가기
- 홈 화면에 추가(앱처럼 설치) 지원
- 지도를 불러오지 못해도 목록과 길찾기는 사용 가능

## 카카오맵 설정 (필수)
[카카오 개발자 콘솔](https://developers.kakao.com) → 내 애플리케이션 → 앱 → 플랫폼 키 → JavaScript 키 → **JavaScript SDK 도메인**에 사이트 도메인을 등록해야 지도가 표시됩니다.
(제품 설정 → 카카오맵 사용 설정도 ON이어야 합니다.)
예) GitHub Pages: `https://gmlduqzhd123-lab.github.io`

## 구글 시트로 맛집 관리하기
코드 수정 없이 시트만 고치면 지도에 반영됩니다.

1. 구글 시트 첫 줄(머리글)을 아래처럼 만듭니다.

   | name | city | category | menu | lat | lng | link |
   |---|---|---|---|---|---|---|
   | 건봉국밥 | 순천 | 국밥 | 국밥, 수육 | 34.950730 | 127.493822 | https://place.map.kakao.com/11105953 |

   - `city`: `여수`, `순천`, `광양` 중 하나
   - `category`: 자유롭게 입력 (입력한 종류로 필터 버튼이 자동 생성됨)
   - `lat`/`lng`: 위도/경도. **비워두면 카카오맵 장소 검색("도시 + 식당이름")으로 자동으로 찾습니다.**
     같은 도시의 음식점·카페 중 이름이 맞는 곳만 인정하고, 못 찾으면 지도에서 숨깁니다.
     다른 지점이 잡히는 등 위치가 틀리면 카카오맵에서 장소를 우클릭해 좌표를 직접 넣어 주세요.
   - `link`: 카카오맵 장소 주소 (비워두면 자동 검색 결과로 채움)

   아래 칸은 **선택**입니다. 머리글에 추가하고 채우면 화면에 표시됩니다.

   | 칸 | 예시 | 설명 |
   |---|---|---|
   | `hours` | `11:00-21:00` | 영업시간. 자정을 넘기면 `18:00-02:00` |
   | `closed` | `월` 또는 `월,화` | 쉬는 요일 |
   | `price` | `1만원대` | 가격대 |
   | `phone` | `061-123-4567` | 전화 버튼 생성 |
   | `image` | `https://...jpg` | 정보창 위쪽 사진 |
   | `note` | `주차 가능, 웨이팅 있음` | 한줄평·메모 (검색에도 걸림) |
2. **파일 → 공유 → 웹에 게시** → 게시할 시트 선택, 형식 **쉼표로 구분된 값(.csv)** → 게시
3. 나온 주소를 `index.html`의 `SHEET_CSV_URL = ''` 따옴표 안에 붙여 넣습니다.

시트를 불러오지 못하거나 비워두면 `index.html` 안의 기본 데이터(`FALLBACK_RESTAURANTS`)를 사용합니다.
이름·도시가 비어 있는 행은 건너뜁니다.

**카카오맵에서 못 찾은 식당 확인하기**: 사이트 주소 끝에 `?check`를 붙여 열면 (예: `https://gmlduqzhd123-lab.github.io/YSK-food/?check`) 못 찾은 식당 목록이 뜹니다.
이름을 카카오맵에 등록된 이름으로 고치거나 좌표를 직접 넣어 주세요. 검색 결과는 브라우저에 30일간 저장됩니다(못 찾은 결과는 하루).

> 즐겨찾기와 공유 링크는 식당 **이름**으로 찾으므로, 시트에서 이름을 바꾸면 기존 즐겨찾기·링크가 연결되지 않습니다.

## 사이트 파일을 수정했다면
`sw.js`의 `CACHE_VERSION` 숫자를 올려 주세요 (예: `ysk-food-v1` → `ysk-food-v2`). 홈 화면에 설치한 사용자도 새 버전을 받게 됩니다.
