## 주요 기능

### 1. 이용 모드 전환 및 전국 지역 분할 로드 (FR01, FR02)
- **이용 모드**: `일반 맛집`, `학교 단체식사`, `선수단 식사` 모드를 전환할 수 있으며, 전환 시 선택한 지역·검색어·비교 후보가 그대로 유지됩니다.
- **행사 프리셋**: 현장체험학습(1일), 수학여행(다일), 수련활동, 학교스포츠클럽 대회, 전국소년체육대회, 전국체육대회 프리셋을 제공합니다.
- **지역별 정적 데이터**: `data/manifest.json` 및 `data/releases/<datasetVersion>/regions/<regionCode>.json` 구조로 선택 지역 데이터만 온디맨드 로드하며, 등록 식당이 0곳인 신규 시·군·구도 빈 상태 안내로 안전하게 열립니다.
- **영구 식당 ID**: 모든 식당은 이름이 바뀌어도 깨지지 않는 문자열 영구 ID(`ysk-r-<번호>` 등)를 사용합니다.
  - 단일 식당 공유 링크: `?restaurantId=ysk-r-1`
  - 후보 비교 공유 링크: `?restaurantIds=ysk-r-1&restaurantIds=ysk-r-71`
  - 구형 공유 링크(`?place=식당이름`) 및 구형 즐겨찾기(`ysk-food-favorites`) 자동 호환·이전 지원

### 2. 단체 식사 조건 검색 및 사실 기반 판정 (FR03, FR05, FR06)
- 학생·선수 인원, 인솔·지도자 인원, 1인당 예산(원), 버스 대수, 동시 착석/교대 식사 정책, 방문 날짜·시간대, 대형버스 주차, 이른 아침식사, 도시락·포장 여부를 입력해 후보를 좁힙니다.
- **미확인 정보 추정 금지**: 확인되지 않은 단체 수용 항목은 모두 `'unknown'` / `null`로 유지하며, 검색 결과를 **`확인된 조건 충족`**과 **`추가 확인 필요(미확인 항목 있음)`**로 분리해 표시합니다.
- 모든 공용 정보는 출처(`SourceRecord`), 확인일(`verifiedAt`), 최근 180일 경과 여부(`재확인 권장`)와 함께 표시됩니다.

### 3. 기준점 직선거리 정렬 및 일정·교대 식사·예산 검증 (FR04, FR07)
- 체험처·경기장·숙소 또는 내 현재 위치를 기준점으로 선택하면 직선거리(`직선거리 X.Xkm (실제 도로·이동시간 별도 확인)`) 순으로 정렬합니다.
- 교대 식사(1진·2진) 수용 가능 여부, 식사 예정 시간대(`Asia/Seoul` 기준 브레이크타임·라스트오더·정기휴무 충돌), 정수 원(KRW) 단위의 학생·인솔자 분리 예산 및 숙소 포함 식사(`숙소비에 포함` / `별도 식비`)를 검증합니다.

### 4. 후보 비교·인쇄 요약표·내 행사 관리 및 개인정보 보호 공유 (FR08, FR09, FR10)
- **후보 비교(최대 3곳)**: 수용 인원, 버스 주차, 메뉴 가격, 예상 총액, 출처·확인일을 나란히 비교합니다.
- **인솔자용 인쇄·PDF 요약표**: 행 중간 페이지 잘림(`break-inside: avoid`) 없이 인쇄할 수 있는 요약표를 생성하며, 식당 문의용 텍스트를 클립보드로 복사할 수 있습니다.
- **내 행사 관리 (`IndexedDB`)**: 다일·다끼니 식사 계획, 식당 견적(`CandidateQuote`), 날짜별 식당 확인(`MealConfirmation`), 백업/복원을 지원합니다.
- **허용목록(Allowlist) 공유**: 공개 URL 및 기본 QR 코드에는 공개 식당 ID와 공개 필터만 포함되며, 연락처·개인 메모는 기본 제외됩니다.

- 카카오 지도 SDK가 차단되거나 느린 환경에서도 **목록 검색·필터·상세 정보·후보 비교·내 행사 관리·인쇄 기능은 차단 없이 즉시 동작**합니다.

## 데이터 빌드 및 검증 명령어

Node.js(v20 이상) 환경에서 외부 패키지 설치 없이 바로 실행할 수 있습니다.

```bash
# 1. 정적 데이터셋 재생성
node tools/build-dataset.mjs

# 2. 데이터셋 스키마·체크섬·교차 참조 무결성 검증
node tools/validate-dataset.mjs

# 3. PRD AC01~AC60 전체 자동 테스트 실행
node --test tests/prd-ac.test.mjs
```
